# 动效手感

这套风格的「高级感」一半来自配色，一半来自**动作的一致性**：全片只允许三种缓动、四种动作原型。想加新动作之前，先确认能不能用现有原型表达。

## 1. 三种缓动，够用全片

```js
const lin = x => x;                                                  // 只用于透明度线性
const eo  = x => 1 - Math.pow(1 - x, 3);                             // 进场：快起慢收
const eio = x => x < .5 ? 4*x*x*x : 1 - Math.pow(-2*x+2, 3)/2;       // 位移：两端都慢
const back= x => { const c = 1.7; return 1 + (c+1)*Math.pow(x-1,3) + c*Math.pow(x-1,2); };  // 弹入：过冲
```

| 曲线 | 用在哪 | 不用在哪 |
|---|---|---|
| `eo` | 淡入、文字浮现、出场、数值增长 | 长距离位移（会显得急刹） |
| `eio` | 位移、缩放、变形、镜头 | 淡入（两端慢，开头会"卡"一下） |
| `back` | 标签/胶囊弹出、尺寸回弹 | 透明度（会闪） |
| `lin` | 旋转（匀速转环）、透明度线性段 | 位移 |

## 2. 时长标准

| 动作 | 时长 | 备注 |
|---|---|---|
| 淡入（fade only） | 0.20–0.25s | `io(a,b,.3)` 的开头段 |
| 浮现（fade + 上移 18px） | 0.35s | 所有说明文字统一用它 |
| 位移（同屏内） | 0.35–0.6s | 距离越远越长，不超过 0.8s |
| 变形（宽高/圆角） | 0.3–0.5s | 配套 `eio` |
| 弹入（scale 0→1） | 0.25s | `ps()` 默认 |
| 镜头推近 | 0.6–0.8s | `eio` |
| 出场（缩小 + 淡出） | 0.3s | 先缩到 0.85 再消失，不要直接 opacity 0 |
| 交叉淡化（分段拼接） | 0.14s | 两段重叠，中间不能有黑帧 |
| 字幕入场 | 0.18s | 上浮 20px + 淡入 |

区间函数：

```js
const io = (a,b,d=.3)=>[[a,0],[a+d,1,lin],[b-d,1],[b,0,lin]];   // 淡入-保持-淡出
const ps = (a,s=1,d=.35)=>[[a,0],[a+d,s,back]];                   // 弹入到 s
```

## 3. 四种动作原型

### ① 浮现（Enter）
说明文字、卡片标题、结论标注。**从下方 18px 浮上来**，不缩放、不横向滑入。

```js
act(g, t0, t1, { x, y:[[t0,y+18],[t0+.35,y,eo]], o: io(t0,t1,.25) });
```

### ② 弧线位移（Travel）
主体从一个位置到另一个位置。**必须带控制点**，直线位移显机械。

```js
const ROUTE = [
  [2.0, 2.45, [540,820], [790,1040]],               // 直落
  [2.45, 3.0, [790,1040], [555,560], [1000,780]],   // 带控制点：先右后上，走弧
  [3.38, 4.28, [555,560], [540,1180], [600,900]],   // 下行穿场
];
const [x,y] = route(t, ROUTE);
```

控制点取「起点→终点」中垂方向偏移 20–30%。方向决定观感：向上弧显得"跃起"，向下弧显得"俯瞰"。

### ③ 形变（Morph）
同一个元素改变宽高/圆角/字号，代表"状态推进"。**不换 DOM**，只改属性。

```js
const W  = [[1.3,140],[1.55,780,eo],[2.0,780],[2.4,200]];   // 胶囊展开 → 收起
const RX = [[1.3,70],[1.55,24,eo],[2.0,24],[2.4,16]];       // 圆角跟着变
const LS = [[1.3,4.2],[1.6,5,eo],[2.0,5],[2.4,1]];          // 字号缩放
```

关键：形变时字符位置要跟着重新居中（用 `text-anchor:middle` + `y = fs*0.36`），否则文字会偏。

### ④ 生长（Grow）
线条、条形、进度、路径。用 `pathLength:1` + `stroke-dashoffset`，或宽度按百分比乘缓动值。

```js
// 折线生长
l.setAttribute('stroke-dashoffset', 1 - eo(p(t,t0,t0+.4)));
// 条形生长
bar.setAttribute('width', fullW * v/100 * eo(p(t,t0,t0+.7)));
// 数值滚动
n.textContent = Math.round(target * eo(p(t,t0,t1)));
```

**数值必须等宽字体 + `letter-spacing:0`**，否则滚动时宽度抖动，画面会"跳"。

## 4. 镜头

```js
cam.setAttribute('transform', `translate(540 820) scale(${z}) translate(-540 ${-cy})`);
```

- `z` 只在 **1.0–1.15** 之间。超过 1.2 文字边缘会糊。
- `cy` 是视觉中心，做「跟随主体下移」时改它，等效于摇镜但不会产生透视畸变。
- 全片不做旋转、不做横向摇、不做手持抖动。
- 大段落切换时用一次 0.6–0.8s 的缓慢推近（`z` 1.0 → 1.06）来标记"进入新章节"。

## 5. 分段拼接

长片由多段独立 HTML 拼成时：

1. 每段自带 `window.renderAt = render`，父页可逐帧驱动。
2. 拼接点前后各留 0.14s 重叠，用 `opacity` 交叉淡化。
3. **字幕让位**：交接时旧段字幕必须在淡化开始前 0.05s 淡出，否则两句字幕叠加成双影。这是最容易出的 bug。
4. 同名字幕/大字跨越拼接点时，两段的字号、位置、缓动必须一致，否则交界帧会看到"跳一下"。
5. 拼完必须逐帧检查交界：`t-0.01`、`t`、`t+0.01` 三帧各截一张。

## 6. 节奏（一条 4 分钟片的参考节拍）

| 段落 | 时长 | 元素数量 | 动作密度 |
|---|---|---|---|
| 片头启动 | 0–2.5s | 1 个主体 | 高（每 0.3s 有变化） |
| 定位/背景 | 2.5–20s | 3–5 个 | 中（每 1–2s 一次） |
| 数据段 | 20–90s | 6–12 个 | 高（图表逐步生长） |
| 论证段 | 90–200s | 4–8 个 | 中（机制图逐步连线） |
| 结论/收尾 | 200–255s | 2–3 个 | 低（收束，留白） |

原则：
- **字幕决定节拍**，画面跟字幕走，不反过来。
- 信息密集处（表格、价目表）单屏至少停 2.5s，让人读完。
- 连续两个"高密度"屏之间插一个"低密度"过渡屏，否则观感疲劳。
- 全片至少有一次"静下来"：画面几乎不动，只有光晕呼吸，用于强调关键结论。

## 7. 不该做的动效

| 反模式 | 为什么不行 |
|---|---|
| 弹跳（spring 多次回弹） | 与「系统界面」的冷调冲突，显得玩具化 |
| 旋转飞入 | 廉价，且中文字形旋转后难读 |
| 打字机效果用在长句 | 观众被迫等，节奏崩 |
| 元素逐个从屏幕外飞入 | 八股 PPT 动画，与本风格对立 |
| 闪白/闪绿转场 | 破坏连续感，拼接应靠内容承接 |
| 全屏 wipe 遮罩 | 同上，遮住硬切不算修复 |
| 每个元素都用不同缓动 | 破坏一致性，全片只允许三种 |
