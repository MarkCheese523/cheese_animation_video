# 色板与层次

## 1. 常量定义（直接抄）

```js
const CY = '#bcf500';   // 主色：荧光绿
const BL = '#7cb300';   // 主色暗端
const MG = '#ff4fd8';   // 互补：品红
const VI = '#b48cff';   // 互补：紫
const GY = '#949a90';   // 中性灰
const AM = '#e9ff6b';   // 提示：柠檬绿
// 文字档
const LT  = '#dfff9e';  // 主色亮文字（HUD / 卡标题 / 说明）
const LT2 = '#edffc4';  // 更亮一档（图标描边 / 极小字）
const MU  = '#b9c79e';  // 次级标签
const CARD_TXT = '#d8e6bc';  // 卡片正文（浅灰绿）
```

## 2. 语义分工（最重要的一张表）

| 语义 | 用色 | 典型位置 |
|---|---|---|
| 我方 / 正面 / 达标 / 主线 | `CY` | 本方数据条、达标结论、主路径、强调词 |
| 我方次级 | `BL` | 渐变暗端、非重点描边、二级标签 |
| 对照方（竞品） | `VI` | 竞品数据条、竞品标签、对照组 |
| 基线 / 第三序列 / 禁用 | `GY` | 第三条数据、中性说明 |
| 劣势 / 更贵 / 失败 / 警示 | `MG` | 「低于」「更贵」「未通过」的标注与箭头 |
| 注意 / 提示 | `AM` | 需要读者留意的临时高亮 |
| 结构 / 分隔 / 标注 | `MU` | 轴、网格、注释文字 |

三条硬约束：
1. `MG` 只表示**负面**。用 `MG` 表示「重点」会让人误读成「劣势」。
2. `VI` 只表示**对照**。同屏出现两个以上竞品时，第二个竞品用 `GY`。
3. `AM` 与 `CY` 同色系，两者不相邻（会糊成一片黄绿）。

## 3. 对比度实测（对舞台底 `#050704`）

| 颜色 | 对比度 | 判定 |
|---|---|---|
| `#BCF500` | 15.60:1 | 主色，任何字号可读 |
| `#DFFF9E` | 18.23:1 | 亮文字，最安全 |
| `#EDFFC4` | 18.97:1 | 最高 |
| `#D8E6BC` | 15.37:1 | 卡正文 |
| `#B9C79E` | 11.29:1 | 次级文字下限 |
| `#7CB300` | 8.00:1 | 可做描边，不做小字正文 |
| `#B48CFF` | 7.83:1 | 紫，≥20px 可用 |
| `#FF4FD8` | 7.09:1 | 品红，≥20px 可用，不做小字 |
| `#949A90` | 7.01:1 | 中性灰，刚好过线 |
| `#FFFFFF` | 20.22:1 | 正文 |
| 卡底 `#0A1E0F` 上的 `CY` | 13.44:1 | 面板内主色安全 |
| `CY` 底上的 `#050704` | 15.60:1 | 实心主色块上写近黑字 |

结论：**所有色对底色都 ≥7:1**，所以可以放心用大面积深底。反过来说，如果把底改成 `#0A0A0A` 或 `#111`，荧光绿会失去冷调、整片发脏——底色必须是带绿的近黑。

## 4. 透明度层次

同一颜色靠透明度做层级，不新造颜色：

| 用途 | 值 |
|---|---|
| 网格线 | `rgba(188,245,0,.06)` |
| 分区底 | `rgba(188,245,0,.08)`（如门/框内部） |
| 弱分隔 | `rgba(188,245,0,.12)` |
| 括角 / 次级描边 | `rgba(188,245,0,.45–.55)` |
| 主描边 | 实色 `CY` |
| 光晕内圈 | `rgba(188,245,0,.42) → 0` 径向 |
| 卡片底 | `rgba(8,22,8,.90)`，需要压住背景时 `.96` |
| 字幕带 | `rgba(4,7,4,0) → .85 (28%) → .95` |
| 扫描线 | `rgba(255,255,255,.022)` |

## 5. 旧配色迁移映射（青蓝 → 荧光绿）

把旧版深蓝科技风转成本风格时，按语义替换，**不要按字面替换**：

| 旧值 | 新值 | 语义 |
|---|---|---|
| `#00e5ff` | `#bcf500` | 主色 → 主色 |
| `#3d7bff` | `#7cb300` | 次主色 → 主色暗端 |
| `#7fe9ff` | `#dfff9e` | 亮青文字 → 主色亮文字 |
| `#9ff0ff` | `#edffc4` | 更亮青 → 更亮绿 |
| `#a9b8ff` | `#b9c79e` | 蓝灰标签 → 灰绿标签 |
| `#04060c` | `#050704` | 蓝黑底 → 绿黑底 |
| `#06162c` | `#0a1e0f` | 深蓝卡 → 深绿卡 |
| `#0d4a7a` | `#1f4e12` | 蓝绿渐变端 → 深绿渐变端 |
| `rgba(0,229,255,a)` | `rgba(188,245,0,a)` | 主色半透明，a 不变 |
| `rgba(160,190,255,a)` | `rgba(176,202,132,a)` | 蓝灰半透明 → 灰绿半透明 |
| `rgba(4,6,12,a)` | `rgba(4,7,4,a)` | 蓝黑半透明 → 绿黑半透明 |
| `rgba(8,20,40,.95)` | `rgba(8,22,8,.95)` | 卡底 |
| `rgba(20,40,80,.95)` | `rgba(10,32,12,.95)` | 卡底（更深一档） |
| `#ff4fd8` | **保持不变** | 品红，本来就是互补色 |
| `#b48cff` | **保持不变** | 紫，本来就是对照色 |
| `#ffd34d`（琥珀） | `#e9ff6b` | 第四色相与主色太近，收编进主色家族 |
| `#6f86b8`（蓝灰系列色） | `#949a90` | 去掉蓝调，退成中性灰 |

**不迁移的颜色**（语义色，改了会失真）：
- macOS 窗口红绿灯 `#ff5f57` / `#febc2e` / `#28c840`
- 终端绿 `#3ddc84`（表示"终端程序"，不是品牌色）
- 报错红 `#c0254a` / `#ff8a85`
- 用户提供的原图截图里的任何颜色（截图是证据，不是设计）

替换后必须做的断言：全库 grep `00e5ff|3d7bff|7fe9ff|a9b8ff|04060c` 应为 0 命中。

## 6. 装饰细节值

```css
/* 括角 */
.corner{position:absolute;width:70px;height:70px;border:3px solid rgba(188,245,0,.55)}
.c1{left:36px;top:36px;border-right:none;border-bottom:none}
.c2{right:36px;top:36px;border-left:none;border-bottom:none}
.c3{left:36px;bottom:36px;border-right:none;border-top:none}
.c4{right:36px;bottom:36px;border-left:none;border-top:none}

/* 扫描线 */
.scan{position:absolute;inset:0;pointer-events:none;
  background:repeating-linear-gradient(0deg,rgba(255,255,255,.022) 0 2px,transparent 2px 4px)}

/* 进度线 */
#prog{position:absolute;left:70px;right:70px;top:140px;height:3px;background:rgba(188,245,0,.12)}
#prog i{display:block;height:100%;background:linear-gradient(90deg,#7cb300,#bcf500);box-shadow:0 0 10px #bcf500}

/* 光晕滤镜 */
<filter id="glow" x="-50%" y="-50%" width="200%" height="200%">
  <feGaussianBlur stdDeviation="6" result="b"/>
  <feMerge><feMergeNode in="b"/><feMergeNode in="SourceGraphic"/></feMerge>
</filter>
```

光晕使用边界：**只给"活的"元素加 glow**（主视觉胶囊、关键数字、当前高亮）。静态面板、表格、说明文字一律不加，否则全屏发光等于没有发光。

## 7. 常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 用 `#000` 做底 | 荧光绿变脏、发灰 | `#050704` |
| 提高主色饱和度到 `#CCFF00` | 屏幕溢出、文字边上出现绿边 | `#BCF500` |
| 品红用作强调重点 | 读者理解成"劣势/警告" | 重点用 `CY` 加粗，只有负面才用 `MG` |
| 主色填充大面积底 | 刺眼、文字读不了 | 主色只做描边/文字/细条 |
| 保留蓝黑渐变 | 画面出现冷蓝与荧光绿互相打架 | 全部转绿黑 |
| 四色同屏 | 没有视觉重点 | 主色 + 一个互补 + 中性灰 |
