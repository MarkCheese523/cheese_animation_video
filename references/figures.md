# 抽象人物与动作系统

本文件保留参数化人物方法。具体真人、品牌角色与具象素材仍须经过现有参考和母版双确认；通用抽象人物不能冒充特定真人。

## 骨架

局部坐标以脚底为原点，y 轴向下：

- 头：圆心 (0,-108)，半径 12。
- 肩：(0,-88)；髋：(0,-52)；躯干从 (0,-92) 到 (0,-52)。
- 腿长 52，臂长 40。
- 角度从竖直向下算起，正值朝面向方向；`face=±1` 表示朝右／左。

人群、主角、智能体通过 token 中的颜色、线宽、虚线、光圈和缩放区分。选中人群成为主角时可用扩散环衔接，不能无关联换人。

## 动作参数

| 动作 | 参数与实现 |
|---|---|
| 自然站立 | `aR=8, aL=-8` |
| 走路 | `walk:[[a,b],…]`，摆幅约 22，相位 `t×13`，身体轻微起伏；位移用 lin |
| 指向 | `aR=120–130` |
| 手持 | `aR=60–75`，物体读 `figHand` |
| 推开 | `aR=150` 持续约 0.2 秒后放下，被推出物体同步运动 |
| 头顶托举 | `aR=165`，物体位于手上约 26px |
| 欢呼／点赞 | `aL=150` 或 `aR=150`，可用 back |
| 打字 | `aR=70+18sin(14t)`，`aL=55+18sin(14t+1.5)` |
| 伸手接管 | `aR=160`，面向交接对象 |

## 人物轨道

```js
const HERO = {
  x: [[t0, x0], [t1, x1, lin]], y: 1200, s: 1.6,
  o: [[t0, 0], [t0 + .3, 1]],
  face: t => t > a && t < b ? -1 : 1,
  aR: [[t0, 8], [t1, 130]],
  walk: [[t0, t1]]
};
figAct(hero, T0, END, HERO);
```

人物不出场时透明度为 0，不销毁节点，保证跨章节身份一致。

## 常用技巧

- **从图标长出人**：圆徽缩成头部，四肢按 grow 生长；`grow=0` 时整体透明，避免零长度圆头线留下圆点。
- **粒子组装**：简单粒子从主体飞向关节，人物淡入、粒子淡出；批量节点不加滤镜。
- **物体交接**：物体位置等于手的位置；交接沿弧线跳到另一只手，可有约 0.1 秒停顿。
- **朝向翻转**：来回走时手持物会左右跳，搬运时优先托举过头顶，或显式设计绕手路径。
- **前后遮挡**：门框、桌面前景放 `over`，人物放 `figs`。
- **人群循环**：`x=start+((t-t0)*speed+i*gap)%distance`，两端按距离淡入淡出。
- **动作资产生成**：现有按镜头生成最小动作集与 2.5D 预渲染规则继续有效；不能用旋转单张 PNG 冒充新视角。
