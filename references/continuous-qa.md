# 连续舞台 QA、性能与已知坑

本清单与 `qa-delivery.md` 同时执行，不替代现有机器检查、contact sheet 和用户验收。

## 连续舞台专项检查

- [ ] 全片只有一个舞台；持续主体跨镜界 DOM 引用严格相等。
- [ ] 相邻 Sprite 时间窗确实交叠，承接对象在重叠区内连续变形。
- [ ] 每个章节边界有承接对象，检查边界前后至少 0.5 秒。
- [ ] 任意 seek、乱序 seek、重复 seek 后，对象状态与顺序播放一致。
- [ ] 分段首帧复原上一段末帧：摄像机、位置、尺寸、旋转、深度、计数、标签一致。
- [ ] 播放、拖动、`?t=`、`?export` 正常；有音频时预览由音频主时钟驱动。
- [ ] 主视觉不侵入字幕区；文字不超卡片；同一时刻只有一个焦点。
- [ ] 数字有来源，“示意”和“据原图计算”标注完整。
- [ ] 原图完整 contain，不裁切、不变形，展示时长达标。
- [ ] 字幕时间、纠错、高亮、断行正确，最多两行。
- [ ] 各分段 TOTAL 一致，时间码为 `mm:ss.cc`。
- [ ] 换 token 后叙事代码与关键帧不变，无颜色／字体魔法数泄漏。
- [ ] 控制台无错误；contact sheet 覆盖镜界 6–12 帧而非只有起中末。
- [ ] 对所有语义段落边界、句中动作和段落结束点逐一执行 `renderAt(t)`；任一异常立即失败，不继续截图或交付。
- [ ] 未来时间窗的 Sprite 不可见，已结束 Sprite 不残留；运行中断造成的“未来元素叠加”不能靠截图猜原因。
- [ ] 持续主体跨句 DOM 引用一致，且母结构在句界前后仍存在；形态或主体关系确有演化，不是只保留元素。
- [ ] 有音频时文件存在、`readyState >= 2`、时长有效且实际可播放；音频时长必须覆盖片段终点，不能把其他短样片的配音复制来冒充完整原音。
- [ ] 使用完整配音制作片段时，必须真实连续播放至片段末尾，验证越过旧结束点仍不中断、末句字幕出现；随后验证重播与拖动的时间换算。逐点 `renderAt` 和 `readyState` 检查不能替代这项实时播放验收。

可执行检查：`node scripts/qa-continuous-runtime.mjs <page-url> --times 0,1.4,2.75,4.65 --subject '#persistent-subject' --audio '#voice'`。脚本捕获页面异常、逐点渲染、时间窗、DOM 身份和音频状态；失败必须非零退出。语法检查和 PNG 存在均不能替代它。

## 已知坑

| 问题 | 原因 | 解决 |
|---|---|---|
| 父组隐藏子元素仍显示 | 子元素自身 visibility 覆盖父级 | 子逻辑用 `upd`，或让子窗口不超过父窗口 |
| 停留期间缓慢漂移 | 相距很远的关键帧仍在插值 | 停留末尾补同值保持帧 |
| 横线渐变／滤镜消失 | objectBoundingBox 高度为 0 | 渐变用 userSpaceOnUse；直线不加滤镜 |
| 零长度线出现圆点 | 圆头线帽 | grow=0 时整体透明 |
| 圆角变形闪烁 | rx 大于宽或高一半 | `min(rx,w/2,h/2)` |
| rect 线条绘制失效 | 浏览器 pathLength 支持差异 | 改 polyline 或 circle |
| 手中物左右跳 | 人物 face 翻转 | 托举或显式绕手路径 |
| 插入原图后后续错位 | 时间被挤占 | 列出并修改所有顺延关键帧 |
| 分段进度条跳动 | TOTAL 不一致 | 全部使用全片总长 |
| 时间码超过 60 秒错误 | 只格式化秒 | 使用 mm:ss.cc |
| file:// 图片不显示 | 浏览器本地限制 | 通过本地服务器访问 |
| 动画卡顿 | 滤镜和节点过多 | 主体才发光；批量元素简化 |
| 比较对象换色 | 各章节写死颜色 | 使用全局 token |
| 每帧重设固定属性 | 固定属性放进 render | 只更新随时间变化的属性 |
| 把 2.5D 当真 3D | 只用缩放和位移 | 明确纵深边界；真 3D 另行评估 |
| `x is not defined`，后续画面缺失 | `map` 回调括号错误，运行中断 | 每个代表时间点执行 `renderAt`；异常立即失败，不继续出图 |
| `p is not a function`，未来元素叠加 | 局部 `const p=pill(...)` 遮蔽进度函数 `p(t,...)` | 避免单字母变量遮蔽；逐点渲染并检查控制台与时间窗 |
| 语法通过但场景已坏 | `node --check` 只查语法，PNG 存在只证明截图已写盘 | 浏览器运行时 QA 非零退出后才可目检 contact sheet |

## 性能预算

- 每帧更新节点约不超过 800；同时发光滤镜约不超过 10 个。
- 大型人群使用圆和路径等简单图形，不用完整骨架，不加滤镜。
- 只有变化属性进入逐帧函数；固定文本、字号和结构初始化一次。
- 自动测试至少覆盖：seek 确定性、时间窗交叠、DOM 身份、容器形变、手部跟随、全部 Carry helpers、分段首帧与 token 独立性。
