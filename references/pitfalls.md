## 工程细节备忘

- 每页 duration 自动累加起点，页内 timing 毫秒为相对本页偏移——对轴时拿 SRT 绝对时间减本页起始时间，不要用绝对时间直接填
- `SFX_EVENTS` 的 `at` 是全片绝对毫秒；预览触发条件 `prevMs < at <= ms` 且步进 <250ms（回跳/拖动不触发）
- 配音驱动模式：audio.currentTime 驱动 seekTo，画面严格跟录音走
- 编辑模式 `?edit=1`：data-edit 点改文案、媒体槽上传录屏（IndexedDB）、导出/导入 JSON 存档（含 base64 录屏，跨浏览器迁移用）
- 导出默认无配音（Bella 曾在剪映自己对轴），`--audio` 才合入；每期开工时问一句当期要不要合入
- 交付预览用 `serve.command`（端口 8765），链接交付同时给预览地址和本地路径
- 【静态服务缺 MIME 导致 SVG 图裂（2026-10-29 素材确认板实测）】SVG 文件本身完整且页面返回 200，但服务把 `.svg` 当成 `application/octet-stream`，浏览器仍不会按图片渲染。静态服务必须显式配置 `.svg: image/svg+xml`、`.webp: image/webp`、`.jpg/.jpeg: image/jpeg` 等类型；QA 要逐个请求代表性素材并断言 Content-Type，同时用浏览器检查 `img.complete && naturalWidth > 0`。修改服务配置后需重载预览进程，仅刷新页面不会加载新配置。
- **slot 位置约定（2026-09-18）**：demo 页型的 slot 配在页面根级（`page.slot`），method/ai-paper 配在 `props.slot`——buildXxx 里先做 `page.slot || p.slot` 兼容；配错位置时静默显示 mock 不报错，QA 必须确认录屏槽真的播了视频
- **slot.crop + slot.zoom（Ken Burns，2026-09-18 新能力）**：`fit:"crop"` 把源视频 crop 区域精确映射到槽内（槽 aspect 配成裁切区比例），`zoom:{t0,t1,from:{x,y,s},to:{x,y,s}}` 页内插值推近。场景：桌面产品全屏录屏内容列只占画面 ~51%，手机上看不清；裁到内容列 + 1.2× 推近，正文可视尺寸近乎翻倍。注意：视频晚于首次 seek 加载时 zoom 会丢，loadeddata 里要补 `applyZoom(lastT)`
- 【headless 截图验证视频 seek 的时序坑】frameMode（?t=）只在启动时 seek 一次：若视频元数据未就绪，currentTime 停在 0——已在 bindSlotMedia 的 onloadeddata 里补 syncVideo(lastT,false) 自愈；但大跨度 seek（>10s）在 headless 虚拟时间下仍可能因解码未完成截到首帧，属截图工具限制。交互/导出模式的 rAF 循环逐帧同步不受影响。验证视频段画面优先用小跨度 seek 或直接看导出帧。
- 【页缝闪回第 0 页·穿帮根因（2026-10-01 中网 v3 血泪）】config 页界若存在缝隙（前页 t1 < 后页 t0），`__exportSeek` 未命中任何页时旧逻辑回落到第 0 页——成片在缝隙处闪回开场素材，用户看到"产品段插球场"四五处穿帮。双修复：①引擎兜底改为「最近已开始的页」（已改通用引擎 player.html）②config 页界必须焊死连续（QA 应加页缝检查：逐页断言 t1[i]==t0[i+1]）。
- 【video 页播完掉空背景】video 素材短于页时长时，播完后 video 元素渲染透明，成片尾段变纯背景色死页（下半屏 std=0）。规则：video 页时长必须 ≤ 素材时长-0.1s；收尾镜头一律用静态图（产品首页静帧），禁用 video 撑尾。
- 【机器审片·画面指纹匹配】config 纸面正确≠成片正确。审片方法：成片逐 0.25s 抽帧，与全部素材参考帧（图片本体/视频首+中+尾帧）做归一化灰度相关匹配，强相关（>0.55）出现在不该出现的时段=穿帮；尾帧逐区域 std 检查死黑页。此法可定位"画面和脚本不相关"类问题，交付前必跑。
- 【img2 半屏容器装配 bug（2026-10-01 中网 v3）】CSS 里 `.half{position:relative;width:540px}` 规则写在 `.split-wrap` 祖先下，但 img2 构建函数把两个 .half 直接 append 到页面根、没套 .split-wrap——半屏容器失效，两张图都 absolute inset:0 锚到整屏中心互相叠盖（左边被右边盖住只剩一张小卡），黄分割线孤悬。修复：构建时显式包一层 `split-wrap`（position:absolute;inset:0;display:flex）。已修通用引擎。另：证书类深色卡与页面同底色，分屏 contain 只给 475px 宽显得又小又空——这类对比页优先用「快切两张大图」替代分屏。
