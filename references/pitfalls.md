# 常见问题与修复

## 时间轴与渲染

| 问题 | 原因 | 修复 |
|---|---|---|
| 定格与播放结果不同 | 播放用 CSS 动画，定格用另一套逻辑 | 所有状态统一由 `render(t)` 计算 |
| 导出后动画变硬切 | 连续量只靠 `transition` | 每帧直接写 SVG/CSS 属性 |
| 每次回跳粒子位置改变 | render 内使用随机数 | 使用固定种子或初始化时生成坐标 |
| 页缝闪回第一段 | 场景时间不连续，未命中时默认第 0 段 | 校验连续性；引擎选择最近已开始场景 |
| cue 永远不出现 | timing 使用绝对毫秒或超过页长 | 改为页内相对毫秒并运行校验 |

## 字体与素材

| 问题 | 原因 | 修复 |
|---|---|---|
| 整片回退系统字体 | 只等待 `document.fonts.ready` | 使用 `fonts.check()` 并抽帧确认 |
| SVG 返回 200 仍不显示 | MIME 为 `application/octet-stream` | 配置 `image/svg+xml`，检查 `naturalWidth` |
| 点阵人物重新出现五官 | 点阵密度读取照片亮度或内部边缘 | 只用外轮廓和坐标／固定种子点阵 |
| 品牌看起来近似但比例不对 | 用基础几何重画 | 使用确认矢量路径并比较路径数据 |
| 录屏关键 UI 被裁 | 全局统一 `cover` | 按页选择 contain、cover 或明确裁切区 |

## 字幕与音频

| 问题 | 原因 | 修复 |
|---|---|---|
| 画面与字幕双层复读 | 把口播整句复制到场景 | 画面只保留关系、关键词和结论 |
| 字幕压关键内容 | 全局固定底部位置 | 按场景调整字幕安全区并抽帧检查 |
| 拖动音频失败 | 静态服务器不支持 Range | 实现 206 与 `Content-Range` |
| 总时长对不上 | 场景边界与 SRT 分开手算 | 从句界生成场景边界并校验字幕末帧 |

## 工具与交付

- 用 `node --check` 检查 JS，不通过 import 执行带副作用的脚本。
- QA 截图必须来自实际浏览器，不用 DOM 存在代替视觉检查。
- PNG 文件大小只能辅助发现空白，不能替代像素与人工检查。
- 修改服务器后重启临时服务，仅刷新页面不会更新 MIME 配置。
- 测试后关闭自己启动的服务器与浏览器，不遗留后台进程。
- 没有实际导出文件和复检结果时，不声称已交付成片。
