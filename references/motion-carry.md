# 连续镜头与承接（Carry）

## 基本模型

- **Stage**：一个 SVG 世界 `#cam` 与一台摄像机，全片不重建舞台。
- **Sprite**：`S(el, t0, t1, fn, name?)`，注册即隐藏，仅在时间窗内可见并逐帧执行；`upd` 只执行逻辑，不改可见性。`name` 会写到元素的 `data-name`，供 lint 报错定位。`t1 ≤ t0` 或 `fn` 非函数直接抛错。
- **动作**：`act(el, t0, t1, {x,y,z,s,r,o}, fn)`，属性支持常数、关键帧数组或函数。
- **关键帧**：`kf(t,K)` 支持数值与数组插值；`route` 支持分段二次贝塞尔路径。
- **纯渲染**：`render(t)` 只由时间与配置决定，任意 seek 后结果一致，不依赖上一帧。
- **主时钟**：有音频时预览由音频时间驱动；无音频才用 performance 时钟。导出仍逐帧调用 `renderAt(t)`。
- **片段音频偏移**：场景本地时间 `t` 对应原始完整配音的 `t + audioOffset`。读取时使用 `t = audio.currentTime - audioOffset`；播放、重播、拖动和键盘 seek 写入 `audio.currentTime = t + audioOffset`。播放器滑杆、时间码、字幕与结束判断全部使用本地 `t`。

## 原则

1. 相邻 Sprite 时间窗至少交叠 0.2–0.5 秒，承接在重叠区发生。
2. 先写“谁留下、怎么变、变成什么”，再写运动代码。
3. 非承接元素用约 0.25–0.4 秒退场，或缩小并被吸入主体。
4. 环境运动可保持画面活着，但不能替代每句的语义主动作。
5. 禁止 `display:none` 互斥切场、整页淡出淡入、闪屏、故障、色相偏移和无关滑动。

## Carry helpers

| API | 含义 | 实现要点 |
|---|---|---|
| `morphRect` | 容器变容器 | 插值 `[x,y,w,h,rx]`，圆角钳制到宽／高一半；内容交叉交接约 0.2 秒 |
| `zoomThrough` | 推入对象成为新场景 | 对象与内部内容同步缩放、淡入；看完可缩回下一容器 |
| `hop` | 沿弧线跳转 | `route` 二次贝塞尔，两端位置与速度连续 |
| `gather` | 多元素汇成主体 | 同步向目标移动、缩小、淡出，目标在同一拍出现 |
| `emit` / `scatter` | 主体分出多个元素 | 从共同中心出发，按 0.04–0.12 秒错开 |
| `unroll` | 环展开成线或反向 | 对环上与线上对应点插值 |
| `bend` | 直线弯成弧或闭环 | 点列插值，端角连续 |
| `retract` | 子元素收回母体 | 半径与缩放同时趋于 0 |
| 父组缩放 | 整体体系缩成样本 | 内容放入共同父组，主体状态用同一坐标换算 |
| 持续主体 | 跨章节保持身份 | 长关键帧轨道；隐藏用透明度／时间窗，不销毁重建 |
| 物体跟随 | 物体粘在人物手上 | 每帧 `figHand(K,t)`，交接用 hop |
| 世界画布 | 镜头移动看不同坐标 | CAM 关键帧，跨段首帧完全复原 |

这些 helper 是可直接调用的实现，不是只在文档里出现的名字。

## 与字幕同步

- 有 SRT 时，关键词视觉强调落在该词前约 0.1 秒至后约 0.2 秒；列举对象按说出顺序出现。
- 数字在提到时开始计数，并在句尾前完成。
- 无 SRT 时只写相对顺序与估算节奏，明确待对轴，不伪造毫秒级同步。

## 摄像机与 2.5D

优先移动对象完成承接，摄像机只做强调。`CAM=[[t,[cy,zoom]],…]` 控制推拉；`act` 的 `z` 与 `project` 控制透视深度。深度值是 2.5D 构图参数，不是 WebGL 三维坐标。跨段时首帧的摄像机、深度与主体状态必须等于上一段末帧。

## v2.1 加固：校验、lint 与震屏

引擎 v2.1 起，易错写法从「静默错图」改为「立即抛错」，并提供运行时常量检查。冻结规则不变：引擎仍唯一，禁止修改与私有接口。

**参数校验（抛错）**

- `kf(t, K)`：K 必须是 `[[t, 值, 缓动?], ...]` 且时间严格递增，否则 throw。
- `setBox(el, [cx, cy, w, h, rx])`：世界坐标盒子写入，强制五个数字，rx 自动夹紧到短边一半。会变形的元素配合 `kf` 使用；`morphRect` 内部同样校验形态数组。
- `S(el, t0, t1, fn, name?)`：校验元素类型、时间窗、`fn` 类型；注册即 `visibility:hidden`。
- `TX` 对象形态：`TX({text, x, y, size, color, mono, ...}, t0, t1)`，text/size 缺失或非数字直接抛错；原位置参数形态保留兼容。新代码一律用对象形态，消灭位置参数写错类 bug。

**`?lint` 自动检查**

- 网址加 `?lint` 运行：引擎每 0.25 秒采样一帧，结果列在右上角面板，点击某条跳转到对应时间。
- 静态检查：字幕超 2 行、单行超 14 字（英文数字按半个字）、字幕时间重叠或倒置、精灵时间窗越出本段范围。
- 动态采样：元素越安全区（左右 60px，字幕区 y≥1360 禁止进入，数值与 stage-layout.md 一致）、文字互相重叠（相交面积超较小者的 25%）、同屏文字超 10 处、父组已隐藏而子精灵仍在显示。
- 豁免：元素或祖先带 `data-free` 可跳过越界检查（`mkFig` 人物已自带，允许从画外走进）；脚本错误直接渲染到同一面板。
- 引擎 API：`lintStatic({T0, END, SUBS, sprites})` 可在 Node VM 中跑静态部分；`runLint` 仅浏览器使用。

**震屏**

`boot({ ..., SHAKE: [[t0, t1, 幅度], ...] })`：窗口内相机 x 按正弦衰减偏移，只配合仪式动作（盖章、雷击）使用，窗口外相机完全复原，不影响逐帧导出的确定性。

**环境运动与画面活性**

光晕呼吸、风扇、扫描线、粒子漂移属于环境运动；任何时刻画面至少一处环境运动，但它不替代每句的语义主动作（与「原则」第 4 条一致）。
