# 全量回归清单（Regression QA）

> 适用场景：每期新视频的装配期、以及任何对已有项目的**修改**（改文案／改 timing／加页型／动样式）。改动越多，回归越要跑全。
> 原则：**AI 自己先跑完所有检查再交付，用户是验收者不是 QA。**

## 一、先定改动级别，再定回归深度

不是每次都全量回归——按改动级别选档，级别判断错误才是真正的风险：

| 级别 | 改了什么 | 回归深度 |
|---|---|---|
| **L1 纯数据** | 只改本期页面的文案、timing、拍顺序；`subs.js` 重新生成 | `npm run validate:motion` 全绿 + **改动段**抽帧目检 |
| **L2 样式/场景** | `assets/template/player.css` 追加/修改、`assets/template/scenes.js` 加渲染分支、新增场景类型 | L1 全部 + **全部段**抽帧目检 + 检查共享样式污染 |
| **L3 引擎/导出** | `templates/engine.js` 时间轴核心、`scripts/export.js`、`scripts/qa_frames.py` 本身 | L2 全部 + 真跑一次导出（可只导片段）+ 音效混音验证 |

## 二、自动层（改完就跑）

`npm run validate:motion` → `npm run qa:motion` → `npm run qa:semantic` → `npm run qa:visual`，全绿才算改完。已覆盖：

- 每页 ×3 帧无 JS 异常（console error 逐帧收集）
- 三款字体全部加载（偶发网络字体失败，重跑一次确认不是环境问题）
- **素材响应类型与实际加载**：至少各请求一个 SVG／WebP／JPG／PNG／MP3／MP4，断言 HTTP 200 且 Content-Type 正确；浏览器端断言所有画面 `img.complete && naturalWidth > 0`，页面 200 不能代替素材加载检查
- 无空白帧（纯色占比检测）
- 分辨率 1080×1920、无滚动条
- 导出 UI（?edit=1 工具栏）不进画面
- 总时长 ≈ SRT 末条时间戳（期望值动态解析，换片自动跟随）

**注意**：自动层只证明「没坏」，不证明「好看」。视觉质量靠下面的目检和人工层。

## 三、半自动层（工具产出，人工判读）

1. **全页抽帧目检**：qa-frames 目录按页截图，逐页看一眼。重点看：
   - 文字是否溢出/被裁切/互相遮挡（本次踩过：end-badge 压住金句）
   - 新样式是否污染了别的页（CSS 类是全局共享的，本次踩过：`.ln` 类重名冲突）
   - 槽位比例、花字位置、装饰是否压正文
2. **timing 边界自查**：每个 timing 值 < 本段 duration。超标元素永远不会出现，且自动层查不出来（踩过：印章超页长）。写页面时自查；量纲断言见 `references/scene-types.md` 与 `npm run validate:motion`。
3. **音效时间点**：预览里把进度条拖到 SFX 事件（如 stamp 130066ms）前后 1 秒，确认触发位置和听感。
4. **预览全片过一遍**：`npm run dev -- --host 127.0.0.1 --port 7100` 起服务，不开配音用视觉时间轴过一遍节奏，再上传配音对一遍音画。

## 四、人工层（交付前自查清单，模拟验收视角）

每次交付前逐条打勾：

- [ ] **音画同步 100%**：上传配音从头播到尾，逐句动作 cue 无抢跑/滞后/画面拖尾；视觉机制段按语义组织，不要求每句换场
- [ ] **视觉机制设计自查**：机制表与字幕并排，逐句核对母结构或主体关系是否推进；每个画面都是声音的**补充**——抽象化/标签化/可视化、有信息增量，无双层字幕，也不得以保留 DOM 冒充连续演化
- [ ] **素材双确认（2026-10-29 新增铁律）**：本期人物、品牌、物品、场景等清单完整；每项均有用户确认的参考和风格化母版，资产状态为 `master_approved` 或 `locked`；未确认素材未进入分镜、样片或成片
- [ ] **具象元素参考与母版一致性**：画面里的具象对象来自已确认真实图片，或对照已确认参考制作的风格化资产；原图／母版对照可追溯，无 CSS／SVG／Canvas／emoji 无参考猜画
- [ ] **资产变体一致性**：镜头调用的资产 ID 与版本正确；变体保留母版轮廓、比例和识别特征，无跨镜头重新发明；来源、授权与品牌规范记录完整，无基础几何符号冒充 Logo
- [ ] **说到哪演到哪**：随机抽 5 页，口播讲 X 的时刻画面正在演 X（timing 对轴的最终校验）
- [ ] **内容规则回归**：画面关键词 ≤8 字；金句 ≤3 处；画面无整句复述字幕（v3 的核心规则，改动时最容易破）
- [ ] **音效克制回归**：全片音效数量是否仍是约定的最少集（现在 = 1 处盖章），没有手滑加回来
- [ ] **录屏槽完整性**：槽位数量、比例、时长清单与交付文案一致；纯概念页（滤镜等）确认无槽
- [ ] **新旧页冲突**：本轮没动的页，和上一版对比抽帧，确认没有被间接改坏
- [ ] **结尾有力**：最后一页金句/数据/落版齐全（结尾是记忆点，删减时最容易被误伤）
