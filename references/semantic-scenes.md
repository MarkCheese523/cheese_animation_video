# 语义场景与视觉母结构

本规则统一“逐句对轴”和“连续舞台”：声音按句同步，画面按语义段落组织。字幕句界是动作 cue，不是强制切镜点。

## 先设计机制，再写逐句动作

写代码前先完成：

| 字段 | 要回答的问题 |
|---|---|
| 视觉母结构 | 观众持续追踪的线、环、路径、容器或主体关系是什么？ |
| 形态轨迹 | 它从什么形态变成什么形态？每次变形表达什么？ |
| 持续时段 | 这个机制覆盖哪些句子、从何时到何时？ |
| 跨句承接 | 相邻句之间同一对象怎样继续运动，而不是切走？ |
| 静止帧语义 | 任取一帧，关掉字幕还能看出什么关系？ |

随后逐句写：`旁白 → 本句推进动作 → 声音 cue → 新增关系`。每句有动作不等于每句换场。

## 判断标准

- **换语义才换主结构**：论点、比较对象、因果方向或用户任务改变时，才设计新机制。
- **换句子只推进动作**：同一论点的解释、举例和结果，应让现有母结构继续变形、重排或改变关系。
- **主结构必须演化**：卡片位移、淡入淡出、缩放、呼吸旋转和连线只是运动手段，不能自动成为叙事动作。
- **技术连续不等于视觉连续**：同一 DOM 保留下来但只换标题，仍是静态页；同一结构跨句发生有语义的变形，才是连续机制。
- **参考元素不是画面答案**：Logo、人物和已确认母版只承担识别；能力趋同、成本、技术位置、用户使用等关系必须专门绘制。

## 本次返工的正反例

反例 A：信息图式摆放。分别画“能力趋同”“生态与成本”“第一梯队”“API 价格”，每句换一张卡或一组装饰。看似每句有画面，实际没有关系承接，像 PPT。

反例 B：一句一镜。每句都设计一个新动作，但镜头随句子频繁重置，观众刚理解主体就被切走，节奏过密。

正例：同一组能力点跨越多句持续存在：

```text
梯队主体缩成能力点
→ 连成共同能力前沿线（能力趋同）
→ 弯成生态与成本仪表（使用条件）
→ 闭合成技术雷达（技术位置）
→ 扩展成用户轨道（用户持续使用）
```

字幕逐句更新，动作按句推进，但视觉母结构不随每句话消失。关键不是复用某个 Logo 或 DOM，而是让同一关系结构持续获得新语义。

## 样片验证单位

“先做 1–2 张定风格”只验证皮肤，不能验证叙事。代表样片至少包含一段完整视觉机制：开始形态、至少一次跨句演化、结束形态，以及与下一段的承接。只给静态关键帧或一段入场动画，不得宣称连续机制已经验证。
