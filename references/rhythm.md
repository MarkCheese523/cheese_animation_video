# 节奏与动效硬数字

> 本文件是**节奏与时长的唯一权威**。表A 的节拍配额、关键词时间公式、动效硬数字都在这里。`SKILL.md` 第零部分只给表结构，本文件给数字与通过条件。

## 语速口径（全仓库唯一）

中文旁白 **280–300 字/分钟 ≈ 每字 0.20–0.21 秒**。

- **写作估算**（没有 SRT 时）：按 300 字/分钟，即 5 字/秒。这是 `SKILL.md` 第二节脚本长度估算的依据。
- **保守下限**（版面排期、预计拍数时）：按 3.6 字/秒。宁可多估拍数，不要少估。
- 两者冲突时**取保守下限**。不要在别处再出现第三种语速。

计字规则：汉字 1 个；一个英文单词或一串数字（`45%`、`V4.1`）算 1 个；标点 0。

## 关键词时间公式

```text
关键词时间 = 句子开始 + (关键词前字数 ÷ 句子总字数) × 句子时长
```

无 SRT 时注明「按字数估算，待对轴」，**不伪造毫秒**。

## 表A · 节拍表与节奏配额

| 项目 | 标准 |
|---|---|
| 一拍时长 | 1.5–3.5 秒 |
| 每条字幕 | 至多 1 个主拍（可附 1 个次要动作） |
| 新视觉事件间隔 | 每 2–3 秒一个；画面最多 4 秒无新变化 |
| 元素最短停留 | 文字约 1 秒；数字数据卡约 1.5 秒 |
| 入场时机 | 可比关键词提前 0.3–1 秒 |
| 强调时机 | 落在关键词时间 −0.1 ~ +0.3 秒内 |
| 仪式动作配额 | 震屏/盖章每 30 秒最多 1 次 |

字幕拆分：每屏最多 2 行、每行不超过 14 字（英文数字算半个）；长于 3.5 秒按逗号拆，拆点优先逗号、其次关键词之前。

| 拍 | 起止 | 字幕(拆分后) | 关键词@时间 | 拍类型 | 视觉动词 |
|---|---|---|---|---|---|
| 1 | | | | 引入/展开/强调/承接/停留 | 从动词表选 |

**通过条件**：字幕不超限；每拍时长在 1.5–3.5s；每拍有且只有一个视觉动词；仪式动作不超配额。

## 动效硬数字

- 每个元素生命周期四段缺一不可：**出生 → 驻留(环境运动) → 变化(形态/位置) → 退场或承接**。
- 缓动分工：`back` = 出生弹入/盖章；`eo` = 到达/绘制/生长/计数；`eio` = 位移/变形/摄像机/归档；`lin` = 淡入淡出/走路位移/循环。
- 同一时刻最多 2 个主运动，其余只能是环境运动；任何时刻画面至少一处环境运动。
- 相邻 Sprite 时间窗交叠 0.2–0.5 秒，退场与入场在重叠区交接。
- 摄像机默认不动，只做 1.0→1.03 轻微推拉；话题切换可移 10–20px；震屏只配仪式动作（幅度 12px、0.3s，`SHAKE` 已内置）。

## 与字幕同步

- 有 SRT 时，关键词视觉强调落在该词前约 0.1 秒至后约 0.2 秒；列举对象按说出顺序出现。
- 数字在提到时开始计数，并在句尾前完成。
- 无 SRT 时只写相对顺序与估算节奏，明确待对轴，不伪造毫秒级同步。
