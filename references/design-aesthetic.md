# 设计审美层：现状诊断与长期建设

> 定位：视觉/动效/审美是这套模板的**核心资产**，不是顺手完成的工序。
> 现状自评 70 分（Bella 校准，2026-09）。这个分数不是否定——两期从零到能用已经跑通——但它必须被明确承认为「未完成态」，并有一条持续向上的路线。

## 〇、视觉铁律（硬约束，优先级高于下面一切审美判断与建设方案）

**1 · 具象元素必须有已确认参考，禁止无参考凭空绘制。** 画面中出现任何真实、具象的对象——人物、品牌、实物物品、产品界面、真实场景——先按 `asset-pipeline.md` 联网搜集参考并主动请用户确认。可直接使用来源与授权清楚的真实图片，也可**对照用户确认的参考**进行抠图、轮廓提取、描边、有限矢量化、配色映射和纹理统一；风格化母版必须再次经用户确认。严禁不依据参考就用 CSS／SVG／Canvas／emoji 猜画或凑数。抽象装饰可以手绘，但必须服务叙事。风格化不自动消除版权或商标风险，来源、授权和品牌规范仍需单独核查。

**2 · 画面与字幕严禁高度重合，必须有信息增量。** 页面文案不能是字幕的复读。画面要做抽象化、标签化、可视化——动效的出现要有必要性：呈现结构/关系/对比/机制，或提供字幕之外的新信息。如果画面文字跟字幕一模一样，这页动画就不要做。双层字幕 = 没做动画。

**3 · 设计阶段自查三条（对轴时的 checklist）。** ①是否按语义段落设计视觉母结构，并逐句检查其推进动作 ②声音 cue 是否与动作同步，视觉段落边界是否落在语义变化处，而非强制页界＝句界 ③画面是否是字幕和声音的**补充**——主体关系可见、有信息增量，而非复读或只有装饰运动。任何一条不过，回炉，不进交付。

**4 · 禁止用基础几何符号冒充品牌 Logo（2026-10-29 用户定死）。** 不得用星形、多边形、圆形等简单 SVG／CSS／Canvas 图形拼装、近似或替代品牌标识，也不得把这类简陋符号当成高级视觉主体。品牌标识只使用来源可靠、比例正确的官方或授权矢量素材；没有合适素材时，改用有完整排版层级的纯文字标识或不指向特定品牌的抽象结构。装饰符号必须承担叙事功能，禁止为了填空或伪造品牌感而添加。

**5 · 母版确认不等于使用正确（2026-11-05 用户返工）。** 母版只锁定可复用的识别特征，不要求每个镜头原样出现，更不允许把点阵、描边等风格机械铺满人物头部和身体。人物实例必须检查材质是否破坏识别与洁净度；点阵造成霉点、噪点或廉价贴纸感时，改为无五官、平涂、留白或局部纹理的合规变体，并按变更范围重新确认。手里是否持卡、持卡数量与动作必须由镜头语义决定，不得让静态母版和动态任务卡重叠。

**6 · 构图必须参与叙事。** 不用“上方图表＋下方小人＋大片空白”凑成解释页；通过尺度、遮挡、前后层级与持续运动表现关系。例如“技术位置退后、真实价值前进”应让榜单缩小淡入背景，同时用户任务继续向前，而不是把两者分别摆在页面上下。标题、标签、人物和卡片同属一个时间轴，标签不得提前出现，退后元素不得压住新主体。

以上铁律先于 design brief、先于 token、先于任何「好看」的判断。

## 一、为什么现在只有 70 分（差距诊断）

1. **没有设计定稿环节。** 每期实际流程是「边写代码边调视觉」：AI 凭 CSS 手感直接产出，没有参考物、没有视觉基准，第一版的简陋是流程的必然结果，不是意外。大量试错迭代才勉强到现在的样子——试错本身消耗了本可以用来打磨的轮次。
2. **魔法数遍地，一致性靠运气。** 颜色、字号、间距、圆角、动效时长与曲线都是逐处手写的数值。`--ink/--pink` 等变量只是色板的一小部分；没有字号阶梯、没有间距系统、没有动效档位。风格统一目前靠「记得上期怎么写的」。
3. **视觉元素上限低。** 贴纸、图形、装饰全部是 CSS 硬画 + emoji。CSS 画的手绘感有限（不规则形状只能用 border-radius 近似）；emoji 跨平台渲染不一致、且和手账风格并不真正匹配。没有 SVG 素材库、没有纸纹/噪点/胶带等质感资源。
4. **动效语言不统一。** 每个页型的 transition 各自手写，时长和曲线没有统一语法——「拍上」的回弹曲线在十几处重复出现却没抽成变量。整支片子的动效「性格」不稳定，时快时慢、时脆时肉。
5. **缺审美反馈回路。** 「这个视觉好不好」目前只有 Bella 验收时凭感觉一条通道，没有沉淀机制：哪些页被夸过、哪些被批过、为什么——这些信息每次都在对话里流走，没有变成下一期的起点。
6. **字体排印未成系统。** 三款字体定了（title/body/num），但字号层级、字重、字距、行高的使用规则没有定义，每个新页面都在现场决定。

## 二、建设方案（四件事，按顺序做）

### 1 · 设计定稿前置（流程改造，零开发成本，立即生效）

在 SOP 的 config 对轴**之前**插入 design brief 环节：

```
素材齐 → design brief（对齐视觉方向）→ config 对轴 → ……
```

design brief 内容（半页纸，不追求完备）：
- **参考**：3~5 个参考物（优秀 motion design 片段、同类账号的封面/内页、海报），说明各借鉴什么
- **色板**：本期主色/强调色/纸色，附具体色值
- **字体使用规则**：本期三款字体各承担什么角色
- **贴纸语言**：本期贴纸元素清单（胶带/印章/回形针/手绘圈重点……）
- **动效性格**：一句话定义（如「快脆、有纸感、仪式时刻放慢」）
- **视觉母结构**：本期观众持续追踪的线、环、路径、容器或主体关系
- **形态轨迹与持续时段**：母结构在哪些语义句之间怎样变形，每种形态表达什么
- **跨句承接与静止帧语义**：句界只推进动作；任取一帧也能看见关系
- **金句位**：本期 2~3 处金句的页面和呈现方式

**和 Bella 对齐 brief 之后才动代码。** 这符合协作铁律，也把「审美试错」从代码轮次里挪到了纸面上——改一张 moodboard 比改一千行 CSS 便宜得多。风格参考只定皮肤，代表样片必须另验证一段完整视觉机制及其跨句演化。

### 2 · Design Token 化（一次建设，长期约束）

把散落的魔法数收进 `:root`，形成完整 token 层，规则是**新样式只允许用 token**：

| Token 类 | 内容 | 示例 |
|---|---|---|
| 色板 | 语义命名（非描述命名）：`--ink / --paper / --accent / --hl-yellow / --hl-pink` | 已有雏形，补语义命名 |
| 字号阶梯 | 5~6 档封顶：`--fs-hero(170+) / --fs-big(90+) / --fs-kw(46~58) / --fs-sticker(38~44) / --fs-note(30~)` | 现状每页现场发明 |
| 间距/圆角/阴影 | `--sp-1~4`、`--r-card/--r-sticker`、`--shadow-sticker` | 现状裸写 |
| **动效档位** | `--t-fast(.12s) / --t-mid(.3s) / --t-slow(.5s)` | 统一节奏感 |
| **动效曲线** | `--ease-pop`（拍上回弹）`--ease-inPaper`（纸落） | 曲线统一 = 动效性格统一 |

这是从 70 分到 80 分性价比最高的一步：不改变风格，只把已有风格**锁死**，让每个新页面自动继承整套质感。

### 3 · 素材库建设（突破 CSS + emoji 的上限）

- **SVG 贴纸库**（贴纸库）：手绘箭头、圈重点、下划波浪、胶带、回形针、印章、撕纸边缘。SVG 是路径级手绘感，且导出逐帧渲染稳定（不依赖系统 emoji）
- **质感资源**（质感素材库）：纸纹、噪点、格子底纹的贴图或 SVG filter——现在格子纸底是 CSS 画的，可升级
- **来源**：AI 生成 SVG（可控、可批量）、开源手绘素材库（注意授权）、Bella 手绘扫描（最有人格，长期方向）
- 落库规则：每个素材标注适用场景；页型库引用素材而非内联

### 4 · 皮肤化：theme 拆 base + skin

`assets/template/player.css` 拆成两层：
- **base.css**：布局、页型骨架、动效语法（用 token）——跨风格稳定
- **skin.css**：色彩、质感、贴纸语言——每个账号/风格一套（做旧手账 → 科技号皮肤；未来：心理学号、极简瑞士风、复古印刷风……）

换肤 = 换 skin + 换素材库，base 不动。这是「一个引擎服务多个账号」的最终形态。

## 三、长期建设节奏（不追求一次到位）

- **每期一次视觉复盘**（5 分钟，写进 SOP 收尾）：本期最好看的 3 页 / 最丑的 2 页，各一句话为什么。结论累积进本文件第五节
- **灵感库滚动补充**：平时刷到好的 motion/视觉参考随手存（对话里发给 AI 即可入册），每期 design brief 从灵感库里取材而不是现场找
- **AI 侧定期调研**：每隔几期做一次动效/排版趋势调研，反哺 token 和页型库
- **复盘结论驱动迭代**：连续多期被批同类型问题（如「文字太多」「装饰压正文」）→ 升格为 skill 规则；连续被夸的模式 → 抽成新页型/新 token

## 四、当前开发环境缺什么（采购清单）

| 缺什么 | 影响 | 优先级 |
|---|---|---|
| design brief 流程/模板 | 每期视觉方向靠现场发挥 | **P0，立即**（纯流程，零成本） |
| 完整 design token 层 | 一致性靠记忆 | **P0**（一次建设） |
| SVG 贴纸库 | 视觉上限被 CSS+emoji 锁死 | P1 |
| 统一动效语法表 | 动效性格不稳定 | P1（并入 token） |
| Golden Frames 视觉回归 | 改动可能无声劣化 | ✅ 已实现（2026-11-08，`templates/kit/visual-regression.js`，见 regression-qa.md 第五节） |
| 灵感库/moodboard 机制 | 参考靠临时搜索 | P2 |
| 字体排印规范 | 字号现场发明 | P2 |
| 手绘素材扫描管线 | 无人格化资产 | P3（长期） |
