## 一、设计前置

新视觉方向先写半页 design brief，确认后再铺开：

- **参考**：3–5 个参考及各自借鉴点，不拼凑无关风格。
- **色板**：纸色、墨色、主强调色、辅助色和危险／反转色。
- **字体**：标题、正文、数字分别承担什么角色；字体必须可本地加载。
- **素材语言**：点阵、描边、贴纸、纸纹或真实界面如何使用，哪些禁用。
- **动效性格**：例如「快脆、克制、关键反转放慢」。
- **重点画面**：全片 2–3 个记忆点及其对应旁白。

## 二、画面叙事

每段按以下顺序设计：

1. 写出本段正在发生的变化，必须包含动词。
2. 画出动作的初始、转折和结束状态。
3. 确认静音后仍能理解关系或过程。
4. 最后安排标题、关键词和装饰。

避免把报告数字直接等同于图表。数字是结果标注，动作才是画面主体。例如「控制权越过 50%」应表现为标记真实越线，而不只是显示 `50.1%`。

画面文字优先使用关键词、短语和数字。删除画面句后若不损失任何信息，说明它在复读字幕，应改成结构、关系或机制。

## 三、Design token

共享样式集中在 `:root`，新场景优先使用 token：

| 类别 | 建议变量 |
|---|---|
| 色彩 | `--paper`、`--ink`、`--accent`、`--muted`、`--danger` |
| 字号 | `--fs-hero`、`--fs-title`、`--fs-label`、`--fs-note` |
| 间距 | `--space-1` 至 `--space-4` |
| 形状 | `--radius-card`、`--stroke` |
| 动效 | `--ease-out`、`--ease-inout`、`--ease-back` |

token 只统一语言，不取代逐场景的构图与节奏。不要把具体文案、品牌或人物塞进 token。

## 四、字体与素材

- 字体放本期 `assets/fonts/`，用 `@font-face` 显式注册，并保留合理回退。
- `document.fonts.ready` 不能证明字体成功，QA 要用 `document.fonts.check()` 和实际抽帧共同验证。
- 不用 emoji 充当跨平台稳定的核心视觉素材。
- 具象素材遵循 `asset-pipeline.md`；抽象装饰必须服务叙事。
- 品牌路径风格化前后保持一致，点阵只能填充已确认的真实路径。
- 人物无五官点阵只能由坐标和固定种子生成，不能读取源图明暗重建面部。

## 五、动效语言

连续量必须由时间函数计算：

```js
const p = clamp((t - start) / (end - start));
node.setAttribute('x', mix(x0, x1, ease(p)));
node.setAttribute('opacity', p);
```

- 预览和 QA 定格调用同一个 `render(t)`。
- 固定随机种子；不要在每次 render 时调用 `Math.random()`。
- 转场保持页界连续，缝隙不得回退到第一个场景。
- 音效只保留少量仪式性节点，避免为每次出现都配音效。
- 录屏按内容选择比例与 `contain`／`cover`，逐页检查关键 UI 是否被裁。

## 六、复盘

每期记录最有效的 3 个画面和最需改进的 2 个画面，各写一句原因。反复出现的问题升格为 QA 规则；被验证的动作抽象成新渲染器或 token，而不是复制上一期整段代码。
