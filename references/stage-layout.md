# 单舞台布局与可换肤设计系统

本规范保留布局、组件与密度；颜色、字体、HUD、网格、粒子、扫描线均是可替换皮肤，不是默认视觉约束。

## 画布与安全区

默认逻辑画布 1080×1920，可通过配置适配其他比例。

| 区域 | 默认 y 范围 | 用途 |
|---|---:|---|
| 顶部信息区 | 0–160 | 可选章节信息、时间码、进度；不是必须 HUD |
| 标题区 | 200–360 | 章节标签、图例、设问 |
| 主视觉区 | 360–1300 | 主体与动作，默认视觉中心约 (540, 800) |
| 过渡区 | 1300–1360 | 少量底部标签，避免侵入字幕 |
| 字幕区 | 1360–1920 | 字幕与底部标识，默认字幕顶部约 1470 |

左右安全边距默认 60px，大卡片宽度不超过约 960–980。摄像机标准位：`translate(540 820) scale(z) translate(-540 -cy)`；`cy=820、z=1` 时世界坐标等于屏幕坐标。

## Token 分层

`templates/segment.html` 的 `:root` 与 `window.STAGE_THEME` 是唯一皮肤入口。背景、表面、文字、主强调、次强调、对立、角色色、字体、字幕与装饰均可替换。更换 token 不得改动叙事代码、关键帧、主体身份或数据。

- 每拍最多约 3 种强调色；比较对象的颜色全片固定。
- 卡片填充与描边读 token；文字对比度必须满足实际皮肤。
- 中文正文与数字字体角色可分别设置，不强制等宽或科技字体。
- 估算文字宽度：汉字约 1em、英文约 0.55em；超宽就缩小或断行。

## 组件规格

| 组件 | API | 保留规格 |
|---|---|---|
| 持续主体 | `makeHub` | 圆形、胶囊、卡片等连续尺寸轨道；官方品牌不手绘替代 |
| 胶囊标签 | `pill` / `P` | 高 40–70，圆角与字号随皮肤 |
| 卡片 | `rect` | 默认圆角 14–24，可按 token 调整 |
| 指标卡 | 自定义 | 参考 290×180，三列中心 x=220/540/860 |
| 表格行 | 自定义 | 参考 900×110，行距 130–140 |
| 原图证据卡 | `imgCard` | 完整 contain、白底可配、标题注明 SOURCE |
| 门 | `door` | 宽约 120、高约 210，底边对地面 |
| 图标 | `icon` | 抽象功能图标；不得冒充品牌 Logo |
| 人物 | `mkFig` | 见 `figures.md` 与现有资产确认规则 |

## 图层

从下到上：`under` → `main` → `figs` → `over` → `top` → `labels`。结构、人物、前景遮挡、持续主体和标签各有固定层级；承接背景不得盖住主体。

## 可选装饰

四角框、顶部时间码、进度条、网格、粒子、径向光、扫描线都可独立开关或替换。它们只提供统一感与环境运动，不承担镜界承接，不能成为每期的默认深色科技皮肤。

## 密度

- 同一时刻一个焦点主体，约 3–5 个活跃元素；背景降低视觉权重。
- 新元素出现时，旧元素必须承接、退场或弱化，不能无限堆叠。
- 标签停留至少约 1 秒，数据卡至少约 1.5 秒；复杂原图按数据规范展示更久。

## 纵深边界

引擎支持 2.5D：`act` 的 `z` 深度轨道与 `project` 透视投影可产生靠近／远离、前后遮挡和视差。它不是 WebGL 真 3D，不提供体积、真实光照或任意三维旋转。需要真 3D 时先单独评估，不能把缩放冒充为已解决真实纵深。
