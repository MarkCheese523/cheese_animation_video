# 单舞台布局与元素规范（表C + 表F）

> 本文件是**坐标与版式的唯一权威**。表C 的坐标只能从这里抄；需要新位置时在模板坐标上做 ±整数偏移，并在注释里写明理由。所有坐标已按安全区校验，偏移后不得越界。

## 画布分区（1080×1920 竖版）

| 区域 | y 范围 | 用途 | 硬规则 |
|---|---:|---|---|
| 顶部信息区 | 0–160 | 章节信息、时间码、进度 | 可选 HUD，不是必须 |
| 标题区 | 200–360 | 章节标签、图例、设问 | 标题带高度 230，其下不留元素 |
| 主视觉区 | 360–1300 | 主体与动作 | 默认视觉中心 (540, 800) |
| 过渡区 | 1300–1360 | 底部少量标签 | 不得侵入字幕区 |
| 字幕区 | 1360–1920 | 字幕与底部标识 | **y ≥ 1360 禁止放任何画面元素**（字幕顶部约 1470） |

左右安全边距 **60**：x ∈ [60, 1020]。大卡片宽度上限 960。摄像机标准位 `translate(540 820) scale(z) translate(-540 -cy)`，`cy=820、z=1` 时世界坐标等于屏幕坐标。

## 文字规范

| 用途 | 字号 | 基线 y |
|---|---:|---:|
| 关键数字 | 56–60（等宽） | 按所属元素 |
| 主体名称 | 36–46 | 按所属元素 |
| 标签 | 26–28 | 按所属元素 |
| 地面标签 | 26 | 1240 |
| 注释 | 18（弱化色） | 1274 |

宽度估算：**汉字 ≈ 1× 字号，英文数字 ≈ 0.6× 字号**。文字宽必须 < 容器宽 − 40，进卡片前先算一遍。同屏文字不超过 **10 处**（`?lint` 强制）。同一概念全片颜色不变；同一时刻最多 3 种强调色。

## 表F 元素表

| 元素 | 是什么 | 图层 | 坐标(模板出处) | 出生时间方式 | 死亡时间方式 | 承接自 | 承接给 |
|---|---|---|---|---|---|---|---|

图层取引擎 `L.under / L.main / L.figs / L.over / L.top / L.labels`：光晕与背景放 `under`，人物 `figs`，标签 `labels`，HUD 类 `top`。从下到上顺序固定：`under → main → figs → over → top → labels`。承接背景不得盖住主体。

**通过条件**：坐标都有出处；无元素进 y≥1360；每个元素有出生和死亡；「承接自/承接给」至少一项非空（纯装饰除外）；子元素时间窗不长于父组（lint 检查父隐子显）。

## Token 分层

`templates/segment.html` 的 `:root` 与 `window.STAGE_THEME` 是唯一皮肤入口。背景、表面、文字、主强调、次强调、对立、角色色、字体、字幕与装饰均可替换。更换 token 不得改动叙事代码、关键帧、主体身份或数据。颜色、字体、HUD、网格、粒子、扫描线均是可替换皮肤，不是默认视觉约束。

## 密度

- 同一时刻 **1 个焦点主体**，活跃元素 3–5 个；背景降低视觉权重。
- 新元素出现时，旧元素必须承接、退场或弱化，不能无限堆叠。
- 标签停留 ≥1 秒，数据卡 ≥1.5 秒；复杂原图按 `data-viz.md` 展示更久。

## 可选装饰

四角框、顶部时间码、进度条、网格、粒子、径向光、扫描线都可独立开关或替换。它们只提供统一感与环境运动，**不承担镜界承接**，不能成为每期的默认深色科技皮肤。

## 纵深边界

引擎支持 2.5D：`act` 的 `z` 深度轨道与 `project` 透视投影可产生靠近／远离、前后遮挡和视差。它不是 WebGL 真 3D，不提供体积、真实光照或任意三维旋转。需要真 3D 时先单独评估，不能把缩放冒充为已解决真实纵深。
