## 这是什么

2026 年初，仓库里曾存在一个名为 `.skill-reference/` 的目录，里面是 `references/` 下同名文件的早期副本：

| 文件 | 归档快照行数 | 现行 `references/` 行数 | 行数差 | 差异内容行数 |
|---|---:|---:|---:|---:|
| `asset-pipeline.md` | 136 | 178 | +42 | 62 |
| `design-aesthetic.md` | 99 | 108 | +9 | 15 |
| `commands.md` | 45 | 45 | 0 | 2 |

> 「行数差」= 现行版本多出多少行；「差异内容行数」= `diff` 统计的增删行合计（`design-aesthetic` 15 行、`commands` 2 行，即本仓库修复计划里引用的那两个数字）。

**各文件的具体漂移内容：**

- **`asset-pipeline.md`**（+42 行）：现行版本新增「重要名词清单 + 通用人物需求」前置步骤、语义母版与变体要求；确认板话术改为「重要名词与通用人物置顶」；新增「先提取重要名词，再决定画面资产」小节与「名词 → 语义资产 → 使用时段 → 变体」表。
- **`design-aesthetic.md`**（+9 行 / 15 行差异）：现行版本新增自查项 **5「母版确认不等于使用正确」** 与 **6「构图必须参与叙事」**；新增「视觉母结构 / 形态轨迹与持续时段 / 跨句承接与静止帧语义」三要素定义；Golden Frames 视觉回归一项由「P1 待做」更新为「✅ 已实现（2026-11-08）」；补记 2026-11-05 混元 4 样片返工与 2026-11-06 连续机制复盘两条复盘记录。
- **`commands.md`**（行数相同，2 行差异）：最后一条导出授权表述不同 —— 归档快照写「当前工程不包含自动导出命令」，现行版本写「连续舞台提供 `scripts/export.js` 与 `scripts/concat.sh`」。**归档版的这句在今天的工程里已不成立。**

## 为什么归档而不是直接删

1. **历史可追**：这三份文件随初始提交 `dba47c7` 进入仓库，之后从未被主动维护，也从未被任何代码、文档或脚本读取（全仓库零引用）。归档保留了「当时写的是什么」的对照能力。
2. **漂移已构成误导风险**：同名文件内容不一致，任何按目录名自动加载的假设都会拿到过期规则。
3. **执行路径不受影响**：现行 skill 加载路径只包含 `SKILL.md` + `references/**`，`.skill-reference/` 从来不在其中。
