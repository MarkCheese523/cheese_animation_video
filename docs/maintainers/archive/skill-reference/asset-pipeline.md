# 素材资产定稿与复用流程

> 目的：先确认素材，再把确认结果变成长期资产。人物、品牌、物品、场景等具象信息不得凭空绘制；后续镜头不得绕开母版重新发明。

## 一、强制顺序与两道用户确认闸门

```text
脚本／SRT 拆解
→ 素材需求清单
→ 联网检索候选参考＋来源／授权记录
→ 素材确认板
→【闸门 1：主动询问用户确认参考；未确认则暂停】
→ 对照确认参考制作风格化母版＋原图对比
→【闸门 2：主动询问用户确认母版；未确认则暂停】
→ 锁定母版并登记资产
→ 生成变体
→ 分镜按资产 ID 调用
→ 资产一致性与来源 QA
```

- 两道闸门都是强制交互节点，不是可选建议。
- 到闸门时必须主动展示候选或对比图，并明确问用户确认；不能只在后台记录“待确认”后继续制作。
- 用户未答复、仅说“继续”但没有看到对应确认板、或提出修改时，均不算通过。
- 修改参考或母版后，需要重新确认对应版本。
- 已经确认且适用于本期的既有资产可以复用，但要在本期素材清单中列出；超出原母版的新特征或新风格需要再次确认。

### 闸门 1 的主动询问模板

> 这期需要用到的具象素材已经整理成确认板，包括【人物／品牌／物品／场景】。每项附了候选参考、来源、授权状态和拟保留的识别特征。请你确认每项用哪张参考，或指出需要替换的素材；你确认后我再开始风格化和分镜开发。

### 闸门 2 的主动询问模板

> 风格化母版已完成，确认板里有原图与母版对照，以及计划复用的变体。请确认轮廓、比例和识别特征是否保留准确；你确认后我会锁定为资产，后续镜头只复用这套母版和变体。

## 二、素材需求清单

在画面脚本和分镜开发前，从脚本与 SRT 中识别：

| 类别 | 例子 | 必须记录 |
|---|---|---|
| 人物 | 真实人物、历史人物、虚构角色 | 身份、角度、表情／动作、使用时段 |
| 品牌 | Logo、产品外观、产品界面 | 官方来源、品牌规范、使用时段 |
| 物品 | 钱包、手机、设备、工具 | 外观特征、角度、状态、使用时段 |
| 场景 | 办公室、城市、实验室 | 地点特征、时间、透视、使用时段 |
| 风格资产 | 字体、纹理、抽象结构 | 来源、许可、适用镜头、变体规则 |

每项指定稳定 `asset_id`，并注明是新增资产还是复用既有资产。

## 三、候选参考与素材确认板

1. 每项具象素材优先提供 2–4 个候选；唯一官方标识可使用官方版本作为主候选。
2. 品牌优先官方品牌资源；人物优先本人、所属机构或可信媒体；物品与场景优先来源清楚、授权明确的图片。
3. 每项展示缩略图、来源链接、作者／机构、授权状态、拟保留特征、处理方式和用途。
4. 授权不明时标记“仅参考，不直接使用”，不得将“能下载”视为“可使用”。
5. 描边、改色、简化或其他风格化**不自动消除版权或商标风险**；仍需记录来源与授权，并遵守品牌规范。
6. 不用基础几何、emoji 或记忆中的形状冒充参考图，不用推测补全品牌或人物的关键特征。

## 四、风格化母版：统一轮廓点阵语言

只能以用户已确认的参考为依据。默认使用“外轮廓／真实路径＋内部点阵”的统一风格，并输出原图／点阵母版／必要变体对照。母版修改后仍需重新经过第二次用户确认。

### 人物：无五官轮廓点阵

- 只提取头肩、身体、手势等**外轮廓**，不提取眼、鼻、嘴、眼镜或面部明暗等内部边缘。
- 内部点阵与粒子只能由坐标规则、固定随机种子或抽象参数生成；**不得按源图亮度、色彩、灰度或面部特征改变点阵密度与大小**，避免重新编码五官。
- 不使用双色调照片、半色调照片、面部浮雕、可辨认五官的线稿作为人物母版。
- 保留人物姿态与外轮廓识别即可；团队中的其他真实人物若未确认肖像，只能使用实名文字节点，不生成虚构头像。

### 品牌与物品：真实几何内的点阵

- 品牌 Logo 必须基于已确认的官方或授权矢量路径。点阵只作为路径内部填充，可辅以描边；不得改变路径、比例、字形或各部分的相对关系。
- 生成点阵版前后必须比较路径 `d` 及其他几何数据，确保完全一致；在浏览器中检查图案是否实际加载、字形是否清晰、描边是否过粗。
- 推荐保留 `reference.svg`、`variants/original.svg`、点阵 `master.svg`，以及按需生成的 `ink.svg`、`outline.svg`。原色参考不能被误标为点阵母版。
- 禁止用星形、多边形、圆形等重新猜画近似 Logo。拿不到可靠素材时，使用经确认的纯文字或不指向特定品牌的抽象结构。

### 实名节点与抽象机制

实名节点、连接关系和抽象机制可复用同一套坐标点阵，保持点距、点半径、墨色与点缀色一致。点阵是统一纹理语言，不得用来暗中重建人物面部或伪造未确认的具象物品。

## 五、资产目录与登记

推荐目录：

```text
assets/library/<asset_id>/
├── reference.<ext>       # 用户确认的原始参考
├── master.svg|png        # 用户确认并锁定的母版
├── variants/             # 描边、单色、状态等变体
├── preview.html          # 原图、母版、变体对照（可选）
└── asset.json            # 来源、授权、特征、状态与版本
```

`asset.json` 至少包含：

```json
{
  "asset_id": "brand-example-logo",
  "type": "brand",
  "status": "reference_pending",
  "version": 1,
  "source": {
    "url": "",
    "creator": "",
    "license": "",
    "usage_note": ""
  },
  "reference_file": "reference.png",
  "master_file": "master.svg",
  "identifying_features": [],
  "approved_reference": false,
  "approved_master": false,
  "variants": [],
  "used_in": []
}
```

状态只允许按实际进度使用：`reference_pending` → `reference_approved` → `master_pending` → `master_approved` → `locked`。未同时记录两项确认的资产不得标为 `locked`。

## 六、母版、变体与复用边界

- **母版**锁定轮廓、比例和核心识别特征。
- **变体**只改变已声明的颜色、描边、材质、光影、表情、动作或状态；品牌资产不得违反官方规范。
- **镜头实例**通过 `asset_id` 和版本调用，不在页面代码中内联重画具象对象。
- 需要新增关键特征时回到母版流程，不借“变体”绕开用户确认。
- 修改已锁定母版必须升版本，并列出受影响镜头，重新做资产一致性 QA。

## 七、交付前资产 QA

- [ ] 本期素材清单完整，新增与复用资产均有稳定 ID。
- [ ] 每项具象素材都有已确认参考；没有凭空绘制或临时替代。
- [ ] 风格化母版有原图对照，且已通过第二次用户确认。
- [ ] 来源、作者／机构、授权或使用限制记录完整。
- [ ] 画面中的资产 ID、版本与确认母版一致。
- [ ] 变体保留识别特征，没有跨镜头比例漂移或重新发明。
- [ ] 没有基础几何符号、emoji 或手绘近似图形冒充品牌 Logo。
- [ ] 用户未确认的资产没有进入后续分镜、网页样片或最终成片。
