# Cheese Motion · HTML 动画视频工作台

**不用 Claude，也能做出高级动画。**

同样一支动画视频，别人靠 Claude 这样的顶级模型现场发挥：写分镜、设计画面、调动画，每一步都在烧最贵的 token，换个便宜模型质量就塌方。Cheese Motion 的做法是把顶级模型的判断力**固化下来**——规则、引擎、QA 全部沉淀进 harness，模型只负责照章执行。一份字幕 SRT + 一段配音 + 一份配置，出一支可以逐帧精调的高级动画视频，**用普通模型的价格，拿到顶级模型的产出。**

## 为什么是 harness，而不是更强的模型

顶级模型贵在「临场判断力」，但做视频要的是「稳定地复现」。这条产线把一件事拆成三层，每层都尽量不让模型档位决定结果：

1. **判断力沉淀成规则，普通模型照章执行。** 怎么拆脚本、怎么设计画面、什么算合格，全部写死在 SOP、确认闸门和 QA 脚本里——这套规则本身就是用顶级模型一期一期喂出来的经验。跑产线时模型不需要「聪明」，只需要不跳步骤。
2. **画面质量由引擎兜底，与模型无关。** 所有动画做进确定性的 HTML/SVG 时间轴引擎，`seek(t)` 计算每一帧，可定格、可逐帧导出。动画是引擎演算出来的，不是模型一段段生成出来的——今天和明天渲染同一帧，结果一模一样。
3. **越用越便宜。** 人物、品牌、物品重绘成统一风格的母版后锁定复用，页型和动效跨期累积。第一期建好 harness，第二期开始每期只换配置；模型随时可换，产出不掉档。

## 一分钟看懂流程

```text
提交 SRT + 脚本 + 配音
  → AI 拆解分镜与素材清单      （你确认）
  → 联网找参考图               （你确认）
  → 照参考重绘成统一风格        （你确认）
  → 只做两段样片：开场 + 核心    （你确认）
  → 铺开全片，网页预览
  → 你说「定稿导出」，才导出 MP4
```

全程网页预览，不用下载视频片段来回传；改文案改时间戳就是改一行配置，重跑即可。传统路径改一版要回剪辑软件重来，这里改一行配置、重跑导出。

## 快速启动

```bash
npm run dev -- --host 127.0.0.1 --port 7100
```

打开 `http://localhost:7100/`。无需 npm 依赖安装。

## 检查与 QA

```bash
npm test                 # 语法、Agent 工作流、确认约束、页面与二进制自测
npm run qa:studio        # 整包交接、三次确认、母版和完整预览浏览器验收（需 Chrome）
```
